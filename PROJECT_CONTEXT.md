# AI Tender Agent — Project Context

## 1. Назначение проекта

AI Tender Agent — система для работы с тендерной документацией и коммерческими предложениями поставщиков.

Основные направления:
- обработка тендерных документов;
- извлечение и анализ технических требований;
- юридический анализ закупочной документации;
- проверка доказательств и цитат по исходному документу;
- работа с правовыми актами и их версиями;
- коммерческий анализ товаров и предложений поставщиков;
- импорт и обработка Excel-прайсов.

Проект разрабатывается как расширяемое приложение. Не смешивать независимые функциональные модули без архитектурной необходимости.

## 2. Технологии

Подтверждены исходным кодом:

## 4. Принятые бизнес-решения коммерческого модуля

1. Одинаковый товар у разных поставщиков должен связываться с одной внутренней записью каталога.
2. Для каждого поставщика создаётся отдельное предложение по этому товару.
3. В дальнейшем необходимо предусмотреть постоянную таблицу соответствий:
   «поставщик — артикул поставщика — внутренний товар».
4. Повторные импорты должны использовать сохранённые соответствия, когда они будут реализованы.
5. Дубли товаров внутри собственного каталога необходимо выявлять и устранять отдельно.
6. Excel-прайсы могут иметь разные структуры. Нельзя предполагать один фиксированный формат.
7. Сопоставление столбцов должно быть настраиваемым.
8. Необходимо учитывать наименование, артикул, цену, валюту, единицу измерения, количество, сроки поставки и срок действия цены — в зависимости от доступных столбцов.
9. Необходимо сохранять ссылку на исходный файл и происхождение импортированных данных.
10. Импортированные цены считаются непроверенными до отдельной проверки.

### Нормализация единиц и количества

- `app/commercial/unit_normalizer.py` — нормализация единиц измерения и безопасное преобразование по правилам товара.
- `app/commercial/quantity_parser.py` — извлечение количества из строк прайс-листа с сохранением исходного значения и статуса разбора.
- Неоднозначные значения и несовпадающие единицы не должны автоматически использоваться в расчётах.
